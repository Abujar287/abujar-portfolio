# Abujar Al-Gifari — Data Analyst Portfolio

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Framework: Vite.
4. Build command: `npm run build`
5. Output directory: `dist`

## Before deployment
- Replace `/public/Abujar-Al-Gifari-CV.pdf` with your actual CV PDF.
- Replace `your-email@example.com` in `src/main.jsx` with your email.
- Replace GitHub URL with your actual GitHub profile.
- Add project screenshots later if desired.
